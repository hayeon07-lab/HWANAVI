# 🚗 HWANAVI | 화내비

> **화는 대신 내고, 운전은 안전하게.**

화내비(HWANAVI)는 운전 중 발생하는 스트레스와 분노 상황에서  
운전자의 감정적인 행동을 줄이고 안전운전에 다시 집중할 수 있도록 돕는 Android 기반 프로토타입입니다.

운전자의 위험·스트레스 신호가 감지되면 미리 녹음된 **대신 화내기 음성**을 재생하고,  
이후 짧은 **안정 안내 음성(TTS)**을 제공하는 방식으로 설계했습니다.

---

## 💡 핵심 아이디어

운전 중 화가 난 상태에서 운전자가 직접 감정을 표출하는 대신,

**감지 → 안전 상태 확인 → 대신 화내기 → 진정 안내 → 운전 집중**

순서로 동작하는 것이 화내비의 핵심입니다.

---

## ✨ 주요 기능

### 1. 대신 화내기 음성
- 미리 녹음된 MP3 음성 재생
- 캐릭터 및 강도별 음성팩 구조
- 사용자 MP3 음성 가져오기
- 음성 미리듣기
- 음량 조절

### 2. 안전 상태 확인 후 재생
위험 신호가 발생했다고 바로 음성을 재생하지 않고  
안전 상태가 확인된 경우에만 재생하도록 설계했습니다.

새로운 위험 상황이나 연결 해제가 발생하면 재생을 중단하도록 구성되어 있습니다.

### 3. 분노 관련 음성 인식
Android SpeechRecognizer를 이용해 음성을 텍스트로 인식하고  
분노 관련 단어가 포함되어 있는지 확인할 수 있습니다.

> 현재 구현은 음성의 감정 강도를 AI로 분석하는 기능이 아니라  
> 음성 인식 결과의 키워드를 확인하는 방식입니다.

### 4. 안정 안내 TTS
대신 화내기 음성이 끝난 뒤 짧은 한국어 TTS 안내를 제공합니다.

날씨 정보를 사용할 수 있는 경우 날씨 기반 문장을 활용하며  
운전자가 다시 안전운전에 집중하도록 안내합니다.

### 5. 날씨 정보
위치 정보를 기반으로 날씨 정보를 조회할 수 있도록 구성했습니다.

- 위치 권한 처리
- Open-Meteo 기반 날씨 조회
- 날씨 기반 안정 안내 문장

### 6. 화내비 캐릭터 & 음성팩
3가지 캐릭터와 3단계 음성 강도를 조합한 음성팩 구조를 제공합니다.

- 아지매
- 절친
- 다정한 친구

음성 강도:

- 순한맛
- 중간맛
- 매운맛

총 9개의 음성 슬롯을 사용할 수 있도록 구성되어 있습니다.

### 7. 운전 리포트 UI
운전 중 발생한 이벤트를 확인할 수 있는 리포트 화면을 제공합니다.

- 일간 / 주간 화면
- 이벤트 카운트
- 이벤트 타임라인
- 그래프 UI
- 운전 평가 UI

현재 리포트는 프로토타입/데모 데이터를 중심으로 동작합니다.

## 🧠 Stress Engine

화내비에는 차량·음성·생체 신호를 함께 판단하기 위한  
Kotlin 기반 상태 머신(Stress Engine)이 구현되어 있습니다.

현재 프로토타입에서는 개발자 테스트용 가상 신호를 이용해  
다중 신호 판단 로직을 검증할 수 있습니다.

주요 안전 로직:

- 서비스 ON 상태 확인
- 사용자 분석 동의 확인
- 신호 연결 상태 확인
- 복수 신호 조건 판단
- 안전 상태 확인
- 재생 대기 시간 관리
- 재생 후 Cooldown
- 새로운 위험 발생 시 즉시 중단
- 센서 연결 해제 시 중단

## 🧪 현재 프로토타입 범위

현재 구현 및 테스트 가능한 기능과 실제 차량 연동 기능을 구분하고 있습니다.

### 구현된 프로토타입 기능

- Android UI
- 서비스 ON/OFF
- 캐릭터 UI 및 상태 표현
- 녹음 MP3 재생
- 한국어 TTS
- 수동 음성 인식 및 분노 키워드 확인
- 안전 미확인 시 음성 재생 차단
- 음성팩 관리 구조
- 리포트 UI
- Stress Engine
- 개발자용 가상 센서 테스트
- 위치/날씨 연동 구조

### 향후 실제 차량 환경에서 연동할 기능

- 실제 차량 데이터 기반 급감속 자동 감지
- 실시간 음성 긴장/감정 분석
- 스마트워치 실시간 심박 데이터 연동
- 실제 센서 기반 3중 신호 자동 판단
- 실제 차량 상태 기반 안전 정차 판단
- 지속적인 백그라운드 모니터링
- 차량 플랫폼 환경 연동

## 🛡️ 안전 설계

화내비는 운전 중 불필요한 조작을 최소화하는 것을 목표로 합니다.

위험 신호가 발생하더라도 즉시 감정 음성을 재생하는 것이 아니라  
안전 상태를 확인한 뒤 동작하도록 설계했습니다.

또한 새로운 위험이 감지되면 진행 중인 음성 재생을 중단하는 구조를 적용했습니다.

---

## 🛠️ Tech Stack

- Kotlin
- Android
- Jetpack Compose
- Android TextToSpeech
- Android SpeechRecognizer
- Android Location API
- Open-Meteo
- Gradle

프로젝트는 다음과 같이 모듈화되어 있습니다.

- `app` — Android 앱 및 기존 기능 연동
- `core` — Stress Engine 및 판단 로직
- `ui` — Jetpack Compose UI 및 음성팩/화면 상태 관리

---

## ▶️ 실행

1. Android Studio에서 프로젝트를 엽니다.
2. Gradle Sync가 완료될 때까지 기다립니다.
3. Android Emulator 또는 Android 기기를 선택합니다.
4. `app` 모듈을 실행합니다.

일부 기능은 위치 및 마이크 권한이 필요합니다.

## ⚠️ 개발 상태

HWANAVI는 현재 **프로토타입 개발 단계**입니다.

향후 실제 차량 환경 및 관련 플랫폼과 연동하여 확장할 예정입니다.

현재 구현되지 않은 기능을 완성된 기능으로 가정하지 않습니다.
