# 화내비 HWANAEBI · Kotlin Jetpack Compose 변환 패키지

완성된 웹 프로토타입을 변경하지 않고 별도로 제작했습니다. 기존 Android 프로젝트에는 접근하지 않았으며 기존 MainActivity.kt, 급제동 감지, 분노/진정 안내 재생 함수를 덮어쓰지 않습니다.

## 먼저 실행하기

1. ZIP을 풀고 이 폴더를 Android Studio에서 **Open**합니다. 기존 프로젝트 폴더 위에 압축을 풀지 마세요.
2. Gradle JDK **17 이상(17 권장)**, Android SDK Platform **35**, Build Tools **35.0.0**을 설치합니다. 첫 동기화에는 인터넷이 필요합니다.
3. `sample` 실행 구성을 선택하고 Pleos Connect v2.1.0 에뮬레이터 또는 Android API 26 이상 에뮬레이터에서 실행합니다. 가로 2560×1440 기준, 실제 크기는 에뮬레이터 density에 맞춘 dp입니다.
4. 기본 모드는 `PREVIEW`입니다. 실제 차량·마이크·스마트워치 연결이 없으며 자동 재생하지 않습니다. 화면과 음성 파일 편집을 확인할 수 있습니다.
5. `ui/.../HwanaebiScreen.kt`의 HomePreview / ReportPreview / VoicesPreview / SettingsPreview / DrivingPreview로 각 화면을 Android Studio Preview에서 확인합니다.

```bash
./gradlew :core:test :sample:assembleDebug
# Windows
# gradlew.bat :core:test :sample:assembleDebug
```

## 디자인 보존

다크 네이비 #0B1116 · 패널 #151E26 · 민트 #87E5CF · Noto Sans KR(동봉 OFL)을 사용합니다. 네 메뉴, 귀여운 곱슬머리 아지매/캡 모자 절친/새싹 다정한 친구를 유지했습니다. 웹의 CSS 캐릭터를 Android용 PNG로 재구성했으므로 원본 웹의 브라우저 그라데이션과 픽셀 단위로 동일한 스크린샷은 아닙니다. 폰트·시스템 UI·density에 따라 간격이 달라질 수 있습니다.

간편 주행 모드는 캐릭터를 중앙에 크게 표시하고 상세 메뉴를 감춥니다. 실제 연동 모드에서는 **기존 안전 판단 + 신선한 safelyParked 신호**가 확인되어야 복귀가 가능합니다. 프리뷰 모드의 복귀 허용은 실차 정차 확인이 아닌 비차량 UI 미리보기입니다. 데모 모드는 모든 상태가 가상임을 표시합니다.

## 녹음 기능 확인

음성팩 → 캐릭터/강도 선택 → 대사 편집 → **내 녹음 MP3 추가** → 파일 목록에서 선택 → **음성 미리 듣기**.

각 9개 조합에 여러 MP3를 추가하고 하나를 선택할 수 있습니다. 대사·목록·선택·음량은 앱 재실행 후 유지됩니다. 외부 파일은 앱 전용 내부 저장소로 복사하므로 원본이 이동되거나 원본 제공 URI 권한이 사라져도 복사본을 재생할 수 있습니다. 파일 선택 창이 열렸을 때는 화면 수명주기에 따라 재생을 멈춥니다. 파일이 없으면 **녹음 파일 준비 중**이며 합성 음성·기본 대체 음성을 재생하지 않습니다. 직접 녹음하는 녹음기 기능은 포함하지 않으며, 팀이 만든 MP3를 선택하는 기능입니다.

## DEBUG 시나리오

1. 프리뷰 화면에서 테스트할 캐릭터·강도의 실제 MP3를 먼저 추가·선택합니다.
2. 하단 **개발자 테스트** → **데모 모드 켜기** → **가상 센서 연결 + 서비스 ON**.
3. 5초 안에 **가상 급제동**, **가상 목소리 변화**, **가상 심박 변화**를 모두 입력합니다. 하나라도 없으면 의심 이벤트가 발생하지 않습니다.
4. 기본 안전 정보는 불충족이므로 재생을 보류합니다. **안정 주행 확인 · 가상**을 누르면 선택한 MP3를 자동 재생합니다. 별도의 재생 시작 버튼은 필요하지 않습니다.
5. 재생 중 **새로운 위험**을 누르면 중단합니다. **연결 끊김**도 중단합니다. 안전 정차는 **안전 정차 확인 · 가상**으로 가정합니다.
6. 정상 재생 종료 후 밝은 미소/평온 상태로 돌아가고 30초 쿨다운을 적용합니다.

릴리스 `sample`에는 위 테스트 UI가 포함되지 않습니다. 실제 연동은 테스트 버튼 없이 기존 센서 이벤트가 엔진을 구동해야 합니다.

## 범위와 안전

실제 Pleos 차량 API, 마이크 긴장도 분석, 심박/HRV API 및 워치 연결은 구현하지 않았습니다. 권한을 임의로 승인하지 않으며, 기존 앱에서 실제 연결/권한/안전 판정을 제공해야 합니다. 시간 창·쿨다운·안전 TTL은 검증되지 않은 예시 정책입니다. 이 패키지는 차량 안전 인증이나 스트레스 감소 효과를 주장하지 않습니다. 내부 자동 재생 로직은 구현했지만 실차 자동 작동이 검증된 제품은 아닙니다.

샘플은 전경 Activity 범위입니다. 화면이 중지되면 재생과 안전 허가를 무효화하고 이후 신호를 받지 않습니다. 백그라운드 주행 서비스, 프로세스 재시작 후 감지 복원, Android Automotive/Pleos 배포 정책은 기존 서비스에서 추가 통합해야 합니다. 기존 안전·재생 경로와 새 경로를 동시에 구동하면 안 됩니다.
