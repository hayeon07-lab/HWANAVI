HWANAEBI INTEGRATED PROJECT - WINDOWS QUICK START

1. Right-click HWANAEBI_PROJECT_ENGLISH_NAMES.zip -> Extract All.
2. Open Android Studio -> File -> Open.
3. Choose extracted Hwanaebi_Integrated directory, containing settings.gradle.kts.
4. Gradle Sync, then app / Medium Phone API 37.0 / Run.
5. Keep your OLD DaesinHwanaeCAR project unchanged as a backup.
